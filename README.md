# Personal Portfolio Website

This portfolio website was created with the objective of showcasing my professional experience, certifications, courses, publications, and projects in a modern, responsive format.

## Tech Stack

- Next.js 13
- TypeScript
- Tailwind CSS
- React Icons

## Quick Start

```bash
npm install
npm run dev
```
