## Course Overview
Official CCSE (Certified Cloud Security Engineer) training teaches, over 4 days of instruction and virtual labs, the security concepts required for enterprise use of cloud services (IaaS, PaaS, and more), plus the skills to configure and operate secure cloud platforms.

The course covers not only technical cloud security, but also business continuity, GRC, and regulatory considerations needed to apply cloud to business. It is recommended for cloud and network engineers as well as planning and management teams evaluating cloud adoption. Hands-on labs with real cloud services make required settings and controls easier to understand.

## Learning Objectives
By the end of this course, participants will be able to:
- Plan, configure, implement, and maintain secure cloud environments for the organization
- Protect, detect, and respond to threats in cloud network infrastructure
- Understand cloud-specific security practices including penetration testing, forensics, incident response, BC/DR, and GRC
- Prepare for the EC-Council CCSE (Certified Cloud Security Engineer) exam
