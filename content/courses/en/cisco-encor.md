## Course Overview
This course covers the core technologies needed to configure medium- and large-scale networks. It focuses on configuring, troubleshooting, and managing enterprise wired and wireless LANs, and on understanding security principles in the enterprise network.
Modern networks also need to be implemented from orchestration tools and programs. The course covers how to build overlay networks with SD-Access and SD-WAN solutions, as well as automation and programmability.

## Learning Objectives
- Acquire the core networking skills needed to configure, troubleshoot, and manage enterprise wired and wireless networks
- Understand and implement security principles in the enterprise network
- Understand how to overlay network design using solutions such as SD-Access and SD-WAN
- Understand enterprise network automation and programmability
