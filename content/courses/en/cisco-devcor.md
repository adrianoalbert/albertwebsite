## Course Overview
This course covers specialized knowledge for designing, developing, and debugging applications using Cisco APIs and platforms, and for managing and deploying applications on Cisco infrastructure. To get the most from the course, 3–5 years of experience designing and implementing applications on Cisco platforms is recommended.

## Learning Objectives
Upon completing this course, you will be able to explain:
- Architecture characteristics and patterns that improve application maintainability
- Steps to design and build ChatOps applications
- Robust REST API integration and implementation
- Procedures for protecting user and system data
- Automation tasks in the application release process
- Application deployment
- Distributed systems design methodologies
- Infrastructure configuration management and device automation concepts
- Network configuration and telemetry using YANG data models
- Comparisons and requirements of relational and non-relational databases
