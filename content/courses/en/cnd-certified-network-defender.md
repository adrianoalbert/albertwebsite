## Course Overview
Network engineers build and manage enterprise and hybrid (enterprise + cloud) environments. When they can defend, detect, respond, and anticipate security risks from the early stages of an incident, organizations minimize damage and reduce risks during network build and rebuild efforts.

CND (Certified Network Defender) is a network security course that helps organizations create and maintain a comprehensive network security system. It develops the skills security technicians need to identify what to review and test, and to prevent and mitigate network risk.

## Learning Objectives
By the end of this course, participants will be able to:
- Gain broad knowledge of network security design, build, and operations, including zero trust / endpoint security, cloud security, and virtual network security
- Analyze and respond to security incidents
- Acquire fundamental security controls and technical skills
- Prepare for the international Certified Network Defender exam
