## Course Details
- **Duration**: 2 days

- **End Date**: July 22, 2020
- **Level**: Intermediate
- **Lab Environment**: Remote Lab Access

## Course Overview
This course covers the standard security features of Linux systems and how to configure them. After understanding various attack types, you will be able to apply appropriate security settings based on requirements.

## Learning Objectives
- Understand the importance of information security and identify threats to information assets
