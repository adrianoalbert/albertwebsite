## Course Overview
This course teaches how to manage Azure subscriptions, secure identities, administer infrastructure, configure virtual networks, connect Azure to on-premises sites, manage network traffic, implement and create storage solutions, scale virtual machines, implement web apps and containers, back up and share data, and monitor solutions.

## Learning Objectives
- Secure identities with Microsoft Entra ID and users/groups
- Manage subscriptions, accounts, Azure Policy, and role-based access control (RBAC)
- Administer Azure with Resource Manager, the portal, Cloud Shell, Azure PowerShell, CLI, and ARM templates
- Configure virtual networks including planning, IP addressing, Azure DNS, and network security groups
- Configure site-to-site connectivity solutions such as VNET peering, Virtual Network Gateway, and site-to-site VPN
- Manage network traffic with routing, service endpoints, Azure Load Balancer, and Azure Application Gateway
- Implement, manage, and secure Azure Storage accounts, Blob Storage, and Azure Files with File Sync
- Plan, create, and scale Virtual Machines
- Manage Azure App Service and Azure Container Instances
- Back up files, folders, and Virtual Machines
- Monitor Azure infrastructure with Azure Monitor, Alerts, Log Analytics, and Network Watcher
